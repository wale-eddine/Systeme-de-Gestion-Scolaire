# School Management System

JavaFX application for primary school administration with an embedded SQLite database.

## Features
- Authentication with admin and teacher roles
- Student, class, level, subject, and teacher management
- Teacher assignments to classes and subjects
- Grade entry (0-20 scale) and bulletin generation

## Tech Stack
- Java 21
- JavaFX 21
- SQLite (JDBC)

## Project Structure
```
TP_JavaFX/
├── src/
├── lib/
├── bin/
├── run.bat
└── school_management.db
```
